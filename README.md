# 🔍 Basic Port Scanner

This is a simple Python-based port scanner that allows users to scan a target IP address over a specified port range. It’s a great introductory project for aspiring ethical hackers to understand how port scanning works at a basic level.

## Features

- Scans open ports on a given IP address
- Supports custom port range
- Validates IP and port inputs
- Provides clean output of detected open ports

## Requirements

- Python 3.x

## How to Use

1. **Clone this repository**:
   ```bash
   git clone https://github.com/Kimetto969/basic-port-scanner.git
   cd basic-port-scanner
2. **Run the script**:
   ```bash
   python3 port_scanner.py
3. **Follow prompts to enter**:
   ```bash 

   Enter target IP: 127.0.0.1
   Enter start port: 20
   Enter end port: 25

   Scanning 127.0.0.1 from port 20 to 25...
   Port 22 is open
   Scan complete.
   Scanning 127.0.0.1 from port 20 to 25...
   Port 22 is open
   Scan complete.
